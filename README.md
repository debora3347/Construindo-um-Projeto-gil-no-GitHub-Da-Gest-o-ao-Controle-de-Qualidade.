# Construindo-um-Projeto-gil-no-GitHub-Da-Gest-o-ao-Controle-de-Qualidade.
Agile Task Manager

Descrição do Projeto 📌
Este projeto consiste no desenvolvimento de um sistema bãsico de gerenciamento de tarefas, criado como atividade prática da disciplina de Engenharia de Software - Centro Universitário UNIFECAF.
O objetivo do projeto é aplicar de forma prática , de conceitos de metodologias ágeis , versionamento de código , controle de qualidade e integração continua utilizando a plataforma do Github.

🎯Objetivos
. Aplicar conceitos de engenharia de software e metodolia ágeis
.Utilizar o Github para versionamento e gestão do projeto 
. Implementar um sistema básico de gertenciamento de tarefas ( CRUD)
.Criar e organizar tarefas usando o Github Projects (Kanban)
.Implemantar  testes automatizados com Pytest 
.Configurar integraçãi continua com Github Actions
. Simular getão de mudança no projeto

⚒ Tecnologias Ultilizadas 

.Python
.Flask
.Pytest
.Github Actions
.Github Project(Kanban)
